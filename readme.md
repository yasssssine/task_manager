# Task Manager Application

## Project Description
This is a simple Python application that helps users manage their daily tasks using a text-based interface.

## Features
- Add a new task.
- Display all tasks.
- Search for a task using a keyword.
- Exit the program.
- Reject empty task titles.

## Steps Completed
- Created the project folder.
- Created the main.py file.
- Developed the Python application.
- Tested the different menu options.

## How to Run the Program
1. Open the Task_Manager folder in Visual Studio Code.
2. Open the main.py file.
3. Click the "Run Python File" button.
4. Use the menu in the terminal to manage tasks.
